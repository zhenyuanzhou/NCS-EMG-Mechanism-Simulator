# Known deviations and issues (running log)

- **Distal SNAP negative-peak duration ≈0.8 ms in the model** (textbook typical ≈1.3 ms, p.27/p.31). Cause: the Rosenfalck-type single-fibre potential has a strong trailing positive phase, so cancellation truncates the compound negative phase earlier than in vivo. Relative behaviour (proximal stimulation → lower amplitude/area, longer duration; cooling → larger, longer SNAP) is preserved. The single-fibre calibration target remains the textbook 0.5 ms.
- **Needle MUAP durations at the low end of normal** (survey mean ≈5 ms; textbook typical 5–15 ms, muscle/age dependent, p.247). The model's within-unit temporal dispersion was kept small so that normal MUAPs stay mostly triphasic (≤10% polyphasic). Relative changes (neurogenic longer/larger, myopathic shorter/smaller) behave as described.
- **"Discernible MUAP" is a model definition** (≥0.5 mV at the site in the normal muscle, the same units followed in the abnormal muscle) used to illustrate the 5:1 recruitment rule; it is not a clinical criterion.
- In **Compare** mode the anatomy panel shows the parameters of the Explore state, not each compared mechanism (the waveforms and table show the mechanisms).
- First computation of each module builds lookup tables (≈0.3–1 s); later changes are faster.
- **Single-fibre amplitudes**: the needle model (tuned for MUAPs) gives single-fibre potentials of a few hundred µV at 0.1–0.4 mm. Spontaneous single-fibre potentials (fibrillation, myotonic, CRD, endplate spike) are therefore multiplied by an illustrative calibration factor (`spontFiberGain` 0.35) to fall in the textbook fibrillation range (10–100 µV, p.234). PSWs use their own crushed-zone model and are not scaled.
- **PSW duration is short (≈2–3 ms)**: in the crushed-zone model the positive wave lasts as long as the adjacent membrane stays depolarised (the model AP), so the slow return described in the textbook is shorter here. Polarity and the "positive wave" shape are correct.
- **Localization uses one model nerve and muscle for every nerve/muscle**: involvement fractions and lesion sites differ, normal values do not. Lower-limb studies use the same arm-length model; only the involvement differs. Read % of normal.
- **MND is modelled as a single loss of anterior horn cells** at day 0 (no ongoing progression); the "patchy" per-muscle distribution is illustrative.
- **Fibrillation grade and MUAP / recruitment labels in Localization** come from illustrative cut-offs applied to model quantities (fibrillating fraction, fibres per surviving unit, units available); they are not clinical criteria.
- **Myopathy in Localization has no time course** (the day control does not change it).
- **NMJ kinetics are tuned, not measured**: store refill time constants, Ca²⁺ increment, p ceiling, post-exercise facilitation/exhaustion time courses and the pseudofacilitation gain are illustrative values chosen so the textbook behaviours emerge (normal: no decrement; MG: U-shaped decrement; LEMS: low CMAP, >100% increment). MG with rapid RNS shows a large decrement in this model.
- **SFEMG normal limits are not reproduced** (Table 37.3 is age/muscle specific); the app compares with the same model's normal state only. With severe blocking, MCD can become unmeasurable (too few consecutive pairs).
- **H reflex uses the arm-length model nerve**; in adults it is routinely recorded tibial→soleus. Absolute latencies are illustrative; Ia thresholds and the 45% reflex-recruitment ceiling are illustrative.
- **F-wave proximal demyelination** uses a long axilla-to-spinal-nerve segment (hidden lesion site `proximal`); minimal F latency rises only by a few ms at moderate severity because the fastest unaffected axons set it.
- **Display "visible deflection" = 0.05 division** in the technical-factors module is an illustrative reading threshold.
- **Cooling SNAP amplitude**: the increase with cooling uses an illustrative per-°C factor (`coolAmpPerDegC`); without it, dispersion from slower conduction would outweigh the longer single-fibre potentials in this model.
